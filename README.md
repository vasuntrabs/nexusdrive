# NexusDrive – File Metadata Management System

A full-stack Spring Boot application that manages file metadata using REST APIs and an H2 in-memory database.

## Features
- Add file metadata (simulated file upload)
- View stored file list
- REST API integration using Spring Boot
- Simple frontend dashboard using HTML, CSS, JavaScript
- Spring Security configuration
- H2 database for development and testing

## Tech Stack
Java, Spring Boot, REST API, H2 Database, HTML, CSS, JavaScript

## How to Run
```bash
./mvnw spring-boot:run
